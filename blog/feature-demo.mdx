## 文字格式

支持 **加粗**、*斜体*、~~删除线~~、`行内代码`，以及 [超链接](https://www.dsyou.cn)。

```js
function greet(name) {
  return `你好，${name}！`;
}

```

| 图片     | ✅       | 本地/外链均可 |

| 数学公式 | ✅       | KaTeX 支持   |
| 暗黑模式 | ✅       | 一键切换     |
